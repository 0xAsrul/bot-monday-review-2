# One Star for Monday

Competition: `u-clever-harbor-75-one-star-for-monday-9ead4a61`

A single line of plain text: a one-star review of Monday, written as
though Monday were a restaurant. The program prints exactly one line
and writes the same line to `/output/entry.txt`:

> One star. Monday sat me by the door, forgot my coffee, and billed me for a weekend I never finished.

Run with `python3 main.py`. Python 3.13 standard library only.
